The `job-intake` Edge Function accepts automatic job-posting intake from external scripts or agents and inserts valid rows into the existing `jobs` table for one configured user. It requires two custom secrets: `JOB_INTAKE_TOKEN` for the `Authorization: Bearer <token>` check and `JOB_INTAKE_USER_ID` for the target auth user UUID. POST either a raw JSON array of jobs or `{ "jobs": [...] }`; the response reports inserted rows, invalid rows, skipped exact `job_link` duplicates, and possible company/title duplicates. See `docs/JOBS_SETUP.md` section 9 for full deploy and test instructions.
